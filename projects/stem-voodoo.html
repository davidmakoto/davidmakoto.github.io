STEM Voodoo

A full-stack educational community platform serving 4,000+ members, with an AI career-guidance layer on top.

Overview

STEM Voodoo is a full-stack educational community platform I architected and built as lead engineer, now serving 4,000+ members. It runs on a Ruby on Rails backend with a React front end, and adds an AI chatbot layer for career guidance on top of the core community features.

What it does

  • Community forums. Threaded discussions with moderation tooling and real-time post updates.
  • Markdown blog CMS. Staff write and publish posts with autosaved drafts.
  • Admin dashboard. Non-technical staff manage users, content, and RSS-sourced content cards without touching code.
  • Career guidance chatbot (in progress). A RAG pipeline over recorded interview clips will let members ask career questions and get grounded answers.

How it's built

Rails and PostgreSQL serve the core app on Heroku, while a Python microservice on AWS Lambda handles embedding and retrieval (pgvector) for the chatbot, calling the Claude API for generation.
