STEM Voodoo

A hands-on STEM learning project built around interactive, browser-based lessons and experiments.

Overview

STEM Voodoo makes science and engineering concepts something you can poke at rather than only read about. Each topic is built as an interactive piece you run directly in the browser — change an input, watch the outcome change, and build intuition from the behaviour rather than from a static diagram.

The aim was to keep the barrier to entry as low as possible: no installs, no accounts, no setup. Open a page and start experimenting.

What it does

  • Interactive lessons. Concepts presented as things you manipulate, not just text and images.
  • Runs in the browser. No installation or account required to start.
  • Self-contained topics. Each experiment stands on its own, so you can jump straight to what interests you.
  • Built for teaching. Designed to be usable in a classroom or for independent learning.

How it's built

Built as a fast, mostly static front end so pages load instantly and the interactive pieces stay responsive on modest hardware and school networks.
