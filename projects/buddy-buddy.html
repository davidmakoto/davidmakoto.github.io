Buddy Buddy

Optimal classroom seating charts for teachers, generated by a constraint-based solver.

Overview

Buddy Buddy generates optimal classroom seating charts for teachers, replacing manual arranging with a constraint-based solver. It is currently in alpha: the backend is live in production, and the mobile app is built but not yet submitted to the app stores.

What it does

  • Rule-based seating. Teachers set constraints like keep these students apart or seat this student up front, and the solver respects all of them.
  • Four-phase solver. Builds a constraint graph, orders students by difficulty, places them greedily, then refines with simulated annealing — solving a 30-student classroom in one to two seconds.
  • Live solver progress. A WebSocket connection streams progress in real time and lets teachers cancel long runs.
  • Bulk student import. Paste a list of names and the app parses and creates students in one step.
  • Multiple arrangements. Generate, compare, lock, and archive different seating charts per classroom.

How it's built

A Go (Fiber) API on PostgreSQL runs the solver and exposes it over REST and WebSockets to a React Native (Expo) app.
