Images referenced by the site:

| File | Used by |
|---|---|
| `stem-voodoo-logo.png` | original supplied logo (source) |

| `stem-voodoo-banner-dark.png` | unused — dark-theme logo variant |

| `menstruation-station.webp` | Menstruation Station card + detail hero — square app icon |

Where a file is absent the page shows a labelled placeholder rather than a
broken image.

Cards crop to 3:2 and detail heroes to 16:9. Logo lockups use the `is-logo`
class instead, which fits the mark inside the tile with padding rather than
cropping it. Square artwork uses `is-art`, which fits the whole image inside
the frame with no padding, letterboxed against `--logo-bg`.
